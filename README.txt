پروژه Android Studio — آنالیز هوشمند بتن آران (C350)

محتوا:
- اپ آفلاین اندروید بر پایه WebView
- داشبورد فارسی و راست‌به‌چپ
- لوگوهای آران در سربرگ
- ورودی قیمت مصالح، حجم فروش و سربار
- محاسبه قیمت تمام‌شده و سناریوهای فروش عیار 350

روش استفاده:
1) Android Studio را نصب کنید.
2) فایل ZIP را Extract کنید.
3) Android Studio > Open و پوشه AranConcreteAnalyzer_Android را انتخاب کنید.
4) اجازه دهید Android Studio ابزارهای لازم (SDK/Gradle) را دانلود و Sync کند.
5) Build > Build App Bundle(s) / APK(s) > Build APK(s)
6) APK دیباگ معمولاً در app/build/outputs/apk/debug/app-debug.apk ساخته می‌شود.

نکته: این بسته سورس پروژه Android Studio است و APK کامپایل‌شده نیست. برای خروجی APK باید یک‌بار پروژه داخل Android Studio Build شود.
